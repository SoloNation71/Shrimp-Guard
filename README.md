# Welcome to Shrimp-Guard

What is it?
With Shrimp-Guard™ you will have a fully intergrated monitoring system that allows remote management of the enviromentals.
Allowing you to check you temps, PH values, TDS, H20 volume, salinty, connect with a BYO camera system or add into your system package (seeking collaborations).
The main components will be Raspberry Pi 4 or higher or Arduino components. Allowing to keep costs low and also provide just the right tech to keep it all manageable.
